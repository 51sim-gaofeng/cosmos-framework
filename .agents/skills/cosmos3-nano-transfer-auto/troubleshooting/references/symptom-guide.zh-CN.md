# Cosmos3-Nano-Transfer-Auto 常见问题与检查

[英文原文](symptom-guide.md) · [中文目录](../../README.zh-CN.md)

> 本文为中文阅读版。排查时应区分观测事实、可能原因和经过验证的结论。

结合 [共享约定](../../shared/model-contract.zh-CN.md)、
[推理参考](../../inference/references/input-and-execution.zh-CN.md)

<a id="siderear-morphing-front-acceptable"></a>

## 侧／后视角变形，但前视角尚可

- **可能原因：** 相机通道与内容不匹配；WSM 渲染过时或不兼容；
  源数据／控制的裁切或时钟不匹配；把前视描述提供给其他视角；
  或者在排除上述问题后，确实存在模型／泛化能力限制。
- **检查：** 逐一跟踪实际请求中的 `camera_key` → 控制路径 → 检查到的像素；
  对照已验证的映射／标定／来源记录。
  检查实际读取的逐视角 caption，而不只是导出中的场景级字符串。
  探测时序，并在多个时间点检查同步的 50% 叠加图像，记录缩放／裁切方式。
- **修正：** 提出有证据支持的映射／控制／文本修正；
  保留原始数据，并在获得授权后生成新请求。
  不要仅凭叠加效果好就推断物理相机身份，也不要自动交换文件。
- **验证：** 复现提供的参考案例，然后固定权重／设置／随机种子，
  在失败案例中每次只改变一个因素，并检查所有受影响相机。
- **重新核验：** 视角／通道、控制／目标几何和时间、caption，
  然后检查输出几何、运动及视觉质量。

<a id="weatherroad-intent-missing-or-inconsistent-across-views"></a>

## 天气／路面要求未体现，或跨视角不一致

- **可能原因：** 正向／负向文本冲突、逐视角 sidecar 错误、
  共享外观设定不兼容、渲染器语义解释不确定，或模型遵循条件的能力不足。
- **检查：** 解析各相机实际文本，对照四项场景属性和已检查的 WSM 比较含义。
  夜间设定与阳光照射的建筑立面相矛盾；后视画面看不到大海，并不意味着沿海设定失败。
- **修正：** 审核模式下给出有证据的修改建议，不要静默重写。
  生成模式下，基于一份一致的外观记录编写新的逐相机正文。
  保留要求的雨／雾，不要为了提高清晰度而删掉这些条件。
- **验证：** 读取器解析后的文本反映预期正文；
  运行条件匹配的案例并检查受影响视角。
- **重新核验：** Caption 格式、CFG 输入、场景语义及受影响视角。

<a id="requested-frame-count-differs-from-saved-video"></a>

## 请求帧数与实际保存的视频帧数不一致

- **可能原因：** 由 caption 推导的时长、tokenizer 帧网格对齐、
  配套描述文件（sidecar）的范围错误、仅选择首个文本块（chunk），或 caption 起点非零却配对了文件开头的
  初始 RGB／联合控制，或源数据覆盖不足。
- **检查：** 根据推理参考，对比 manifest 范围、生效的 chunk 覆盖设置、
  已解析样本参数、帧 ID，以及探测／解码得到的输出帧数。
- **修正：** 选择实际控制和全部 caption 都支持的对齐区间。
  对于非零起点的源区间，应准备同步裁切，并把 sidecar 帧范围重置到从零开始。
  保留源 FPS。
- **验证：** 按文档说明预处理后，帧数、最终时间戳、初始 RGB 条件和控制一致。
- **重新核验：** 所有传感器选定的时间区间；
  不能只根据 RGB 帧数推断联合输出的 LiDAR 扫描帧数。

<a id="missing-lidar-wrong-sweep-count-or-unexpected-prefix"></a>

## LiDAR 缺失、扫描帧数错误或前缀异常

- **可能原因：** 请求中遗漏 LiDAR 块、缺少 HD-map 控制、
  嵌套前缀字段错误、源 ID 不匹配，
  或文档已说明的训练／推理扫描帧数差异。
- **检查：** 解析后的联合模式、控制路径与目标前缀路径、
  各传感器时间原点、实际输出帧 ID 及预期输出清单。
  视觉预览不能代替对张量单位／掩码／ID 的检查。
- **修正：** 使用受支持的嵌套双向前缀接口和已验证的距离输入格式。
  不要凭直觉转换因果示例的字段，
  也不要把 HD-map 控制重新标注为初始实测 LiDAR。
- **验证：** 距离／强度输出完整且均为有限值，起止时刻的同步对应关系正确。
- **重新核验：** 距离单位、源数据对齐、条件扫描帧掩码及联合输出。

<a id="import-error-oom-or-distributed-failure"></a>

## 导入错误、OOM 或分布式故障

- **可能原因：** 运行时依赖不兼容；CP／CFGP 设备网格（mesh）配置无效；
  源序列长度／视角数量超出内存容量；编译／卸载选项冲突；
  主机数据加载器压力过大。
- **检查：** 保留首次失败和精确命令／环境标识。
  下载数据前，先运行 CLI 帮助或针对性的训练配方检查，并验证副本数量计算。
  区分主机内存不足，以及原始像素处理、VAE 编解码或去噪器计算阶段的显存不足。
- **修正：** 使用匹配的已准备环境，从较小且对齐的冒烟测试开始，
  关闭编译／缓存，并选择当前实现支持的设备网格。
  将 CPU 卸载／暂存视为内存与性能之间的权衡。
  保留注意力设置和严格检查点加载。
- **验证：** 先进行独立的导入／配置检查，再进行规模受限的执行；
  资源允许时，最后执行原始请求。
- **重新核验：** 输出等价性；若修改训练拓扑，还应核验
  batch／学习率／调度的计算及保存／恢复流程。

<a id="storage-read-errors-while-training"></a>

## 训练期间的存储读取错误

- **检查：** 查看最终重试／跳过结果并定位失败路径。
  检查文件访问、工作进程健康状况、解码样本及优化器进度。
- **恢复：** 修正路径、访问或存储问题，同时保留数据集和重试策略。
  将跳过样本与成功读取样本分开统计。
  区分传输错误和授权失败；保持 TLS 验证和配置的样本跳过策略不变。
- **停止：** 按既定次数上限执行重试，不无限延长。
  出现致命故障、重试耗尽、数据无效或达到任务时间上限时，
  停止受影响的任务并保留日志。
  独立且健康的任务应继续运行，允许它们完成检查点／视频导出。
- **验证：** 确认读取恢复，训练使用预期数据继续推进。

<a id="training-resumes-with-wrong-iterationlrema-or-wrong-checkpoint"></a>

## 恢复训练后的迭代数／学习率／EMA 错误，或加载了错误检查点

- **可能原因：** 模型／配置配对错误；误用热启动设置恢复训练；
  同一任务的 latest 指针覆盖了外部检查点路径；把后续启动时的覆盖值误认为源码默认值；
  保存未完成。
- **检查：** 实际加载的产物和状态清单、已解析配置／CLI 覆盖值、
  迭代数、学习率／调度器位置、EMA 历史长度、随机数状态和数据游标。
  检查实际输出目录及加载器选中的检查点。
- **修正：** 使用兼容的已保存任务配置恢复预期的完整检查点，
  或提出一个单独命名的热启动实验。
  保留源产物；未经授权，不得删除 latest 指针或重置状态。
- **验证：** 检查恢复后的第一步，再完成一次保存和重新加载，确认状态均符合预期。
- **重新核验：** 模型、优化器／调度／EMA、数据采样分布／游标，
  以及任何拓扑变化。
