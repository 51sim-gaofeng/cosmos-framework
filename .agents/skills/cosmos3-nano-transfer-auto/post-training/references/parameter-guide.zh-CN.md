# 根据自己的数据和硬件适配训练配方

[英文原文](parameter-guide.md) · [中文目录](../../README.zh-CN.md)

> 本文为中文阅读版。配置键、公式和参考值保持原样。

使用 [四阶段训练配方](canonical-recipe.zh-CN.md) 从 Cosmos3-Nano 开始训练。
若进行直接微调，则加载已发布的 Transfer-Auto 权重，并新建
优化器、调度器和迭代计数器，并重新建立 EMA 历史。

<a id="keep-the-model-and-data-aligned"></a>
## 保持模型与数据匹配

- 遵循 [数据约定](data-contract.zh-CN.md)：物理相机 ID、同步的
  控制/目标、距离投影，以及基于实际录制场景的 caption。
- 保持模型配置和 tokenizer 与权重匹配。所有联合阶段在当前时刻及此前 0.4 秒的窗口内
  使用去重的跨视角注意力；阶段 1 在单视角内使用双向注意力。
- 保留训练配方的可训练模块、条件掩码和损失归约方式。
- 严格遵循训练流程的检查点衔接方式。同阶段恢复会还原该任务的
  模型、优化器、调度器、计数器、EMA 和数据加载器状态。

<a id="settings-to-review"></a>
## 需要检查的设置

| 设置 | 参考值 | 使用或调整方式 |
| --- | --- | --- |
| 训练任务混合比例 | 训练配方中的阶段表 | 可用数据变化时，跟踪实际 RGB／LiDAR 任务占比及各分辨率的采样占比。 |
| 学习率调度 | 分阶段预热与衰减的线性调度 | 阶段 1 → 2 时重置调度器/训练器计数器；阶段 2 → 3 → 4 时保留。保留继承的 EMA 历史步数。新的微调从头初始化。 |
| 微调学习率 | 参考调度下限：`1e-5` | 将其作为初始比较基准；根据损失／梯度稳定性和留出数据上的生成质量调整。结合数据集规模及样本被重复采样的次数设置训练时长。 |
| EMA | 幂律曲线速率 0.1 | 加载继承的 EMA 时保留历史步数偏移；全新微调则初始化新的 EMA。 |
| 噪声、条件和 dropout | 训练配方的分阶段取值 | 从给定概率开始。利用逐任务损失、文本/控制遵循程度及固定的留出场景比较改动效果。 |
| 相机、分辨率和片段长度 | 分阶段时间跨度；480p/720p | 使用已标定视角和同步区间。估算显存时，覆盖计划中最长的序列和最大的 batch。 |
| 打包上限 | 分传感器 / 短序列联合 / 长序列联合分别为 240k / 300k / 1.5M | token 预算中应包含控制、目标和文本。检查打包长度及被拒绝的样本。 |
| 并行度 | CP32/FSDP32 | 根据实际资源选择受支持的设备网格，检查显存、有效 batch 及保存／恢复流程。 |
| 有效 batch | 参考布局下每次更新 16 个片段 | 计算 `world_size / CP × clips_per_replica × accumulation`，并验证实际打包的 batch。 |
| 梯度累积 | 1 | 减少独立数据副本时，在可行范围内增加累积次数，以保持有效 batch。 |
| 精度与重计算 | BF16 计算、FP32 主权重；选择性激活检查点 | 改变重计算或卸载设置后，检查前向／反向计算是否出现非有限值，并测量显存和内存占用。 |
| 数据加载器 worker | 从保守设置开始 | 增加并发前，测量 I/O 和主机内存。跟踪重试次数和数据源采样情况。 |
| 保存、预览及种子 | 训练配方的保存间隔；种子 0 | 在短测试终点保存；固定对照实验的输入和种子。确认检查点已完整保存且能重新加载。 |

例如，将独立数据副本数减半，同时将梯度累积次数加倍，
可以保持相同的逻辑 batch。明确记录学习率和调度器的变更。
并行和内存设置请参阅 [训练指南](../../../../../docs/training.md)。
