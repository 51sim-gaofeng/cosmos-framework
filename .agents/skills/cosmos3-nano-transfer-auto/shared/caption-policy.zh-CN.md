# Cosmos3-Nano-Transfer-Auto 描述文本准备

[英文原文](caption-policy.md) · [中文目录](../README.zh-CN.md)

> 本文为中文阅读版；配置键、代码和接口名称保持原样。

<a id="keep-training-and-inference-captions-aligned"></a>

## 保持训练与推理的描述风格一致

准备后训练标签和推理提示词中的描述文本（caption）时，应采用一致的逐相机描述风格、细节程度及时间约定，
以减小训练文本与推理提示词之间的差异。

- 优先使用**带时间戳的描述**来表达场景及其变化。纯文本的详细段落同样可用，
  但带时间戳的 caption 更接近模型的训练风格；原文报告这种格式的推理效果更好。
  格式请遵循 [caption 指南](../inference/references/caption-guide.zh-CN.md)；
  保留原生逐相机配套描述文件（sidecar）的格式，并保持帧范围同步。
- 物体布局与运动应以同步 WSM 为依据。推理时，从用户或场景元数据获取所需的
  **时段、天气、路面状况和地理环境**；WSM 类别颜色不能提供这些事实。
  训练时，caption 则必须描述实际配对的 RGB／采集数据。
- 联合检查所有视角：同一参与者的外观和物理运动必须相容，场景条件必须一致。
  不同相机中的屏幕空间运动、反射和可见性存在差异是正常的；
  不要把前视描述复制到每个相机，也不要要求每个视角都出现相同地标。
- 只保存场景描述正文。保留训练配方的相机／任务格式化规则：
  Framework 会自动提供相机组（rig）／当前相机的上下文和 WSM 任务指令。
  手动重复这些前缀会改变模型实际接收的文本。

推理时更改目标天气是合理的。但如果只把训练 caption 改成雨夜，
却保持晴天 RGB 目标不变，就会产生矛盾的监督信号。
打包训练数据前检查控制与目标的对齐，并用留出场景比较训练后的模型。

<a id="author-or-review-captions"></a>

## 编写或检查描述文本

对于推理提示词，按照随附的 [caption 指南](../inference/references/caption-guide.zh-CN.md)
生成或扩写描述。

提供同步的 WSM 媒体、已经验证的物理视角映射／渲染器语义、选定时间区间、
上述四项目标属性及其来源、适用时的现有 caption 正文，以及输出目录。
默认对所有提供的相机使用长篇、带时间戳的 caption；
每个视角的各段正文合计 300–400 个词。必须实际查看并检查 WSM；
编写完成后另行开展的视觉复核不是必需步骤。

如果请求只是检查，请使用
[输入准备指南](../inference/references/input-preparation.zh-CN.md)。
报告矛盾并提出修改建议，不要直接重写。
已有的 `captions.json` 是“相机到正文”的映射，不是推理请求。
打包 sidecar 前，检查发布版本的读取器和解析后的文本。

对于训练标签，应改为遵循
[基于真实目标的 caption 指南](../post-training/references/data-contract.zh-CN.md#training-captions)。
推理时可以为将要生成的 RGB 设定合理外观；训练时则不能据此为未改变的真实 RGB
目标编造外观标签。

<a id="caption-text-and-automatic-prefixes"></a>

## 描述正文与自动前缀

每个 sidecar 的 `caption` 字段只保存该相机的局部场景描述；
采用推荐格式时，在正文中包含时间戳。
标准逐视角 Auto 工作流中，Framework 会添加两类不同的模型上下文：

- **相机组与当前视角描述：** 包括选定相机、它们的朝向、镜头类型、
  标称视场角，以及接下来场景描述所属的相机身份。
  这些信息来自选定的 camera key 和配置的相机属性，而不是视觉检测。
- **WSM 控制任务指令：** 系统提示词说明 WSM 控制决定受控物体和道路布局，
  caption 则描述外观及未受约束的背景细节。
  相机／LiDAR 联合任务还会描述 HD-map 控制及相机与 LiDAR 的对齐关系。

训练时通过原生 caption 格式化器和文本 tokenizer 变换添加这些内容；
推理时通过 caption 加载器和模型的文本分词流程添加。
训练配方和推理路径会选择合适的任务模板；
单传感器训练阶段使用自己的格式化方式。
时长、FPS 和分辨率元数据也由配置的格式化器提供。

不要把这些头部内容或系统指令复制进 caption 文件，
也不要用顶层场景提示词替代逐相机正文。
保留提供的训练配方／模型 caption 设置。
对于自定义相机组，应验证相机键映射及标定：
自动添加的标称 FOV 并不能证明物理相机与之匹配。
